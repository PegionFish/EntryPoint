## 二、缺陷清单

### P0-1 浅色主题切换后白屏冻结，不可恢复（高置信）
- **复现**: 侧栏"深色"开关 → 切到浅色。
- **现象**: 整窗只剩浅灰背景色，侧栏与全部内容消失；AX 树显示 89 个元素全部存活（应用状态正常）；等待 10+ 秒、多次截屏均空白；**再次切回深色仍冻结在白屏**，只能重启进程恢复。
- **影响**: 浅色主题完全不可用；且一次误触即令窗口变砖。
- **线索**: `palette.rs:73 light()` 有单测保证与深色不同，故更疑似呈现/重样式路径问题（主题切换触发全量 restyle 后 present 管线停摆），与 P0-2 同类。
- **代码锚点**: `app.rs:711-722`（主题切换+持久化）、`theme::apply_theme`（`app.rs:601`）。

### P0-2 最大化后渲染面冻结于旧尺寸，窗口大面积黑屏（高置信）
- **复现**: 标题栏"最大化"。
- **现象**: 原生标题栏铺满全屏，但 egui 内容仍按旧窗口尺寸（1784x1149）绘制在旧位置，其余区域全黑；等待 2s+ 两帧截屏一致（实时数值同步冻结）。"还原"后布局恢复正常。
- **影响**: 最大化这一基本窗口操作不可用。
- **代码锚点**: 视口尺寸/zoom 处理路径 `app.rs:597-610`（`set_zoom_factor`）、`app.rs:569 fit_window_to_screen`（仅首帧一次性，非本 bug 直接原因但同属视口管理）。

### P1-1 仪表盘"计算设备"行水平溢出，卡片被右缘裁切（高置信，新实例复现）
- **现象**: 1784px 宽下，RTX 5090 D 卡占满大部分宽度，"Intel(R) AI Boost" 卡被右缘切断（openvino 徽章只剩一半），CPU 卡换行到第二行；无换行、无横向滚动提示，被裁内容不可达。
- **排布逻辑问题**: 同页并存三种宽度策略——统计卡行不铺满（右侧留 ~18% 空白）、设备行溢出裁切、模块表只占 ~60% 宽——视觉节奏不统一。
- **代码锚点**: `pages/dashboard.rs` 设备卡布局（与 `components.rs:87 responsive_columns` 的列宽计算相关）。

### P1-2 模块页曾捕获"横向条带破版"帧：卡内容塌成一行、2/5 卡片不可见（中置信）
- **现象**: 多次截屏显示模块卡变成单行横向长条（名称/状态/描述/分隔线/模型变体排成一行并被右缘裁切，全部操作按钮出屏），且 Faster-Whisper、Qwen3-TTS 两卡完全不可见；同一时刻 AX 树结构完整正确，另有一帧与 AX 一致的**正常**渲染（纵向卡片、按钮齐全）。
- **判断**: 若为真，则与 P0 同属呈现冻结/错帧族；AX 稳态正常说明布局代码大概率无碍。**需真机目视复核**。
- **代码锚点**: `pages/modules.rs:564-586 render_module_grid`（`ui.horizontal` + `ui.scope` + `set_width`，scope 继承父级 horizontal 布局时内容会横向溢出，是潜在隐患）。

### P2-1 滚动区无键盘滚动（高置信）
- PageDown/方向键均不滚动仪表盘内容；内容高于视口时（依赖检测区在折叠线以下）键盘用户不可达。egui ScrollArea 默认仅滚轮。

### P2-2 设置页排布细节（高置信，AX+可信帧一致）
- 双列卡片高度不齐，右列"Updates"卡近空；网格右下空槽。
- "💾 保存配置 / 重新加载"是全局动作，却被放在"界面"卡内部，层级与可见性弱。
- 模型缓存目录以相对路径 `models` 显示且在他处被截断省略，与仪表盘页显示的绝对路径不一致。

### P3-1 窗口位置不持久化：重启后在主屏默认位置 (123,114) 打开，而非退出前的副屏位置。

## 三、分页评估

### 仪表盘
- **优点**: 信息架构清晰（统计卡 → 计算设备 → 模块概览 → 依赖检测）；2s 实时刷新可见（VRAM/CPU 数值跳动）；依赖检测把 ffmpeg/torch 状态与修复命令完整透出，排障价值高。
- **问题**: P1-1 溢出；模块表"设备/端口"列在全部停止时整列 `-` 仍占宽，右侧大片空白；依赖检测的英文修复命令（`uv pip install torch --python ...`）直接面向终端用户，语气偏开发者。

### 模块
- **优点**: 模块=模型统一卡信息密度高（版本/状态/类别/描述/变体 radio/来源/VRAM/目录/操作行）；空状态与工具栏（导入/导出/检查更新/刷新/缓存目录+打开）齐备。
- **状态机验证通过**: `▶ 启动` → 徽章"启动中"、汇总条"1 启动中 4 已停止"、随后分配 `:18000` + `cuda:0`、按钮变"⏹ 停止"；`⏹ 停止` 后回到"已停止"、VRAM 释放（574MB 残留后归零趋势可见）。
- **问题**: P1-2 破版帧；卡片操作按钮使用裸 emoji（▶📜🗑🏷），与侧栏线性图标风格不统一。

### 管线 / 任务
- 空状态设计良好（居中图标 + 文案 + 行动按钮 + 页头描述），任务页含状态筛选下拉与"维护"入口。两页在测试宽度下排布正常。

### 设置
- 结构：语言/更新/计算/端口/模型/网络代理/Python/管线引擎/界面 九卡双列；"切换后立即生效，保存配置后持久化"的即时生效模型体验好。
- **i18n 验证通过**: 切 English 后侧栏、页面、空状态全量翻译且即时生效，切回正常。
- 问题见 P2-2。
